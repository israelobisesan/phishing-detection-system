Project Overview

PhishGuard AI is an advanced phishing detection system powered by machine learning. It was developed to address the growing threat of phishing attacks that exploit human vulnerabilities to steal sensitive information.

The system uses a Random Forest classifier trained on a comprehensive dataset of both phishing and legitimate URLs. By analyzing 36+ URL features, it can accurately determine whether a website is safe or potentially malicious.

How It Works

1. URL Input — You enter a website URL you want to check.

2. Feature Extraction — The system extracts 36+ features including URL length, special characters, HTTPS usage, suspicious keywords, and domain characteristics.

3. ML Analysis — A trained Random Forest model processes these features and calculates the probability of the URL being a phishing attempt.

4. Result — You get instant feedback with confidence scores and safety recommendations.

Features We Analyze

Our system examines multiple aspects of every URL:

  • URL and hostname length
  • Number of dots, hyphens, slashes
  • Special character count
  • HTTPS / HTTP protocol
  • Number of subdomains
  • IP address presence
  • TLD analysis
  • Digit and letter ratios
  • URL shortening detection
  • Suspicious keywords
  • Brand name spoofing
  • Obfuscation patterns

Technology Stack

Python 3.9+ Flask Scikit-learn Pandas NumPy HTML5 CSS3 JavaScript Random Forest

Dataset

The model was trained on the PhiUSIIL Phishing URL Dataset from Kaggle:

  • 134,850 legitimate URLs
  • 100,945 phishing URLs
  • 235,795 total samples

The dataset was split 80/20 for training and testing, ensuring robust performance on unseen URLs.

Why Phishing Detection Matters

Phishing attacks have become increasingly sophisticated. According to the Anti-Phishing Working Group (APWG), phishing incidents continue to rise globally, with costs estimated in the billions annually.

Traditional blacklists and rule-based systems struggle to keep up. Machine learning offers a proactive approach that can detect zero-day attacks, adapt to new patterns, and reduce false positives.

Limitations

While highly accurate, no system is perfect. Please be aware:

  • Not 100% accurate — Always exercise caution online.
  • URL-based only — We analyze URL patterns, not website content.
  • Evolving threats — Attackers constantly develop new techniques.
  • False results — Legitimate sites may be flagged or sophisticated attacks may pass.

Recommendation: Use this as one layer of protection alongside antivirus software, two-factor authentication, and security awareness.

Best Practices

  1. Always verify the URL before entering sensitive information
  2. Look for HTTPS and a valid SSL certificate (padlock icon)
  3. Be suspicious of urgent requests or threats
  4. Don't click links in unsolicited emails
  5. Enable two-factor authentication wherever possible
  6. Keep your browser and antivirus updated
  7. Never share passwords via email
  8. Use unique, strong passwords for each account
  9. Verify sender email addresses carefully
  10. When in doubt, contact the organization directly
